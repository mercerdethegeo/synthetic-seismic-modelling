# Synthetic Seismic Modelling Using Python

**Author:** Celine Thompson  
**Project status:** Completed  
**Project type:** Independent learning exercise  
**Software:** Python, Google Colab  
**Data:** Hypothetical subsurface model

## Project Overview

This exercise explores the fundamentals of synthetic seismic modelling using Python. A simplified, hypothetical layered earth model was constructed to investigate how variations in velocity and density influence seismic reflections and the resulting synthetic seismic trace.

The exercise forms part of my independent development in scientific programming and geophysics.

## Methodology

1. Construct a layered velocity and density model.
2. Calculate acoustic impedance.
3. Calculate reflection coefficients at layer boundaries.
4. Calculate two-way travel times and construct a time-depth relationship.
5. Generate 25 Hz and 50 Hz Ricker wavelets.
6. Construct a reflectivity series.
7. Convolve the reflectivity series with a Ricker wavelet to generate a synthetic seismic trace.

## Limitations

This exercise uses hypothetical velocity, density and layer thickness values. No field seismic or well log data were used. The model represents a simplified acoustic, normal-incidence seismic response for educational purposes.
